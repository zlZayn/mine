And provide initial values!</span> <span class="c1"># Pure mathematical expressions, more flexible, does not support interaction term syntactic sugar</span> </code></pre></div> <p>$$\hat{y}=\beta_{0}+f(x_{1},\beta_{1})+f(x_{2},\beta_{2})+\dots+f(x_{n},\beta_{n})$$</p> <ul> <li><code>lm()</code> (Linear Models; Linear Least Squares):</li> </ul> <div class="highlight"><pre><span></span><code><span class="nf">lm</span><span class="p">(</span><span class="n">y</span><span class="w"> </span><span class="o">~</span><span class="w"> </span><span class="n">mathematical_expression</span><span class="p">,</span><span class="w"> </span><span class="n">data</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">dataset</span><span class="p">)</span> <span class="c1"># Linear form (only βx combinations), parameters cannot be explicitly written! <p>$$\hat{y}=\beta_{0}+\beta_{1}x_{1}+\beta_{2}x_{2}+\dots+\beta_{n}x_{n}$$</p> <p>Matrix form:</p> <p>$$\beta^T=\begin{bmatrix} \beta_0 \ \beta_1 \ \vdots \ \beta_n<br> \end{bmatrix}, X= \begin{bmatrix} 1\ x_{1}\ \vdots\ x_{n}\ \end{bmatrix}; \hat{y}=\beta X$$</p> <hr> <h2><code>nls()</code> and <code>lm()</code> Can Transform Into Each Other</h2> <p>When a nonlinear model can be <strong>mathematically transformed</strong> into a linear form, the nonlinear regression problem solved using <code>nls()</code> is equivalent to the linear regression problem solved using <code>lm()</code>. <strong>Both essentially solve the same least squares optimization problem</strong> by <strong>minimizing the residual sum of squares ($SS_{R}$)</strong> to estimate parameters, i.e., minimizing:</p> <p>$$SS_{R} = \sum_{i=1}^n (y_i - \hat{y}_i)^2$$</p> <p>Where $y$ is the observed value and $\hat{y}$ is the model's predicted value.</p> <h2>Illustrative Example</h2> <p>Using <p><code>lm()</code> essentially solves for the coefficients of narrow-sense linear models through <strong>linear least squares</strong>.</p> <p><strong>Both essentially solve the same least squares optimization problem</strong>.</p>
