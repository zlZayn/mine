<p><img alt="" src="https://pic2.zhimg.com/v2-0dee9824ab0579527a569ed5db162467_1440w.jpg"></p> <p><strong>The <code>broom</code> package is used to convert statistical model outputs into tidy data frame formats (<code>data.frame</code>), transforming text information that was originally only for viewing (such as <code>summary()</code>) into structured data frames that can be directly used for subsequent analysis and processing.</strong></p> <hr> <h2>I. Core Functions</h2> <p><code>broom</code> summarizes key information about models in tidy <code>tibble()</code> format. <code>broom</code> provides three verbs to facilitate interaction with model objects:</p> <ul> <li><a href="https://generics.r-lib.org/reference/tidy.html">tidy()</a> summarizes information about model components</li> <li><a href="https://generics.r-lib.org/reference/glance.html">glance()</a> reports information about the entire model</li> <li><a href="https://generics.r-lib.org/reference/augment.html">augment()</a> adds informations about observations to a dataset</li> </ul> <blockquote> <p>Source: <a href="https://broom.tidymodels.org/">Convert Statistical Objects into Tidy Tibbles • broom</a></p> </blockquote> <h2>II.
