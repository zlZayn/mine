Its core function is to generate multiple complete datasets (rather than a single imputation result) through the <strong>chained equations multiple imputation method</strong>. Compared to simple imputation (such as mean imputation), it better preserves data distribution and variable relationships, making it particularly suitable for complex missing patterns.</p> <p><strong>Types of special R objects:</strong></p> <table> <thead> <tr> <th>Special R Object Type</th> <th>Full Name</th> <th>Source</th> <th>Function</th> </tr> </thead> <tbody> <tr> <td>mids</td> <td>Multiply Imputed Data Set</td> <td>Generated by mice()</td> <td>Stores multiple imputed datasets</td> </tr> <tr> <td>mira</td> <td>Multiply Imputed Repeated Analyses</td> <td>Analysis of mids with with()</td> <td>Stores separate analysis results for each dataset</td> </tr> <tr> <td>mipo</td> <td>Multiply Imputed Pooled Results</td> <td>Merging mira with pool()</td> <td>Merges to get final statistics</td> </tr> </tbody> </table> <p>The <code>mice</code> package mainly has the following functions:</p> <ol> <li><strong>Build prediction models for variables with missing values</strong></li> <li><strong>Generate multiple imputed datasets</strong></li> <li><strong>Subsequent batch modeling and integration of results</strong></li> </ol> <hr> <p><strong>Multiple imputation of missing data</strong> → <strong>Batch modeling on multiple datasets</strong> → <strong>Merge model results</strong></p> <div class="highlight"><pre><span></span><code><span class="nf">library</span><span class="p">(</span><span class="n">tidyverse</span><span class="p">)</span> <span class="nf">library</span><span class="p">(</span><span class="n">mice</span><span class="p">)</span> </code></pre></div> <h2>1.
